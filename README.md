# Лабораторная работа № 2

**Дисциплина:** Базы данных  
**СУБД:** PostgreSQL  
**Тема:** Создание запросов  
**Вариант:** 22

## Цель работы

Закрепить навыки создания и выполнения SQL-запросов в PostgreSQL: выборка данных по условиям, создание таблиц на основе результатов запросов, добавление, изменение и удаление записей, применение агрегатных функций.

## Предметная область

База данных почтовых отделений и их графиков работы. Данные используются для анализа режимов работы отделений и выполнения операций над записями.

## Содержание работы

В рамках варианта 22 выполняются семь заданий:

1. Выбрать дни, в которые продолжительность работы отделения превышает 8 часов.
2. Найти отделения, обслуживающие физических лиц и принимающие заказные письма.
3. Создать новую таблицу по результатам выборки с помощью `CREATE TABLE AS SELECT`.
4. Добавить записи на основе данных другой таблицы с помощью `INSERT INTO ... SELECT`.
5. Обновить сведения об обслуживании клиентов с помощью `UPDATE`.
6. Удалить записи, соответствующие условию короткого перерыва, с помощью `DELETE`.
7. Подсчитать количество отделений по дням недели с применением `COUNT` и `GROUP BY`.

## Порядок выполнения

1. Открыть **pgAdmin 4** и подключиться к серверу PostgreSQL.
2. Создать учебную базу данных либо выбрать подготовленную базу для лабораторных работ.
3. Открыть **Query Tool**.
4. Загрузить файл `lab2_gleb_variant22.sql`.
5. Выполнить скрипт и просмотреть результаты запросов во вкладке **Data Output** и сообщения во вкладке **Messages**.

> Скрипт содержит демонстрационную структуру и тестовые записи. При работе с уже выданной преподавателем базой данных названия таблиц и столбцов необходимо согласовать с её схемой.

## Используемые конструкции SQL

`SELECT`, `WHERE`, `CREATE TABLE AS`, `INSERT INTO ... SELECT`, `UPDATE`, `DELETE`, `COUNT`, `GROUP BY`.

## Результат работы

Подготовлены SQL-запросы для семи заданий варианта 22, охватывающие выборку, формирование таблицы на основе запроса, операции изменения данных и группировку с подсчётом записей.

## Вывод

В ходе лабораторной работы рассмотрены основные способы получения и обработки данных в PostgreSQL. Закреплены навыки работы с запросами на выборку, добавление, изменение и удаление записей, а также использования агрегатных функций.
